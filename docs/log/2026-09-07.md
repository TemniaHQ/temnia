## Done

- **The route comparison, at Rajesh's request.** The five S2 research briefs, done the evening
  before by Sonnet agents (687,695 subagent tokens, 241 tool calls, about 9 minutes in parallel),
  were redone by the orchestrating model directly against primary sources: 22 tool calls, 5 minutes
  of wall clock. The agents' facts held; their misses were in files they skipped, not in what they
  read. Seven items changed the plan: the 24-second e2e fixture has no speech (measured: zero
  silences), Temporal owns liveness so there is no transcript reaper, the legacy's duration check is
  one-directional (words past the media end plus two seconds fail, ending early is fine), whisperx's
  `fill_nearest` flag, the player package's own context and hooks, Modal's environment parameter and
  retention windows, and the legacy viewer's virtualisation and follow-scroll rules. Recommendation
  recorded: narrow primary-source questions go to the top model directly; wide reading goes to Sonnet
  with "quote the line, list the files not read"; a verification pass runs before any research claim
  becomes a decision.
- **Implementation, orchestrated.** The top model wrote a spec per slice and reviewed every diff;
  Opus agents built against each spec. Four slices landed on one PR, #20, in one day.
- **Slice A, the ladder on Modal.** A transcode seam (`local` for dev and the gate, `modal` on
  staging); spawn carries the call id in the heartbeat details so a worker restart reattaches instead
  of respawning; progress moves through a Modal Dict; `hls/manifest.json` is written last as the
  completion marker both backends produce. NVENC rungs with forced IDR and no scene cut; decode and
  scale stay on the CPU because NVENC has no ProRes decoder. A CUDA image with BtbN's n8.1 ffmpeg
  pinned by sha256, because Temnia's own ffmpeg is a static musl build with no NVENC. A boot probe
  refuses a wrong token or a contract mismatch before any media touches the function.
- **Slice B1, the transcript backend.** Two tables with forced RLS and probes. The `TranscriptV1`
  contract in Zod and generated pydantic with integer milliseconds, the duration check restated in
  Python because Zod drops refinements from JSON Schema. `TranscribeWorkflow` runs as an abandoned
  child of ingest, started only when the probe finds audio; a non-claimable start is a no-op, and a
  Retrying stage sits between attempts. A provider seam carries WhisperX on Modal and a recorded
  provider for tests; the engine's raw response stays out of the Temporal payload. Ledger rows for
  transcription seconds and revision bytes. Server actions for retry, speaker labels, and corrections,
  with the object written first and an optimistic check inside the update. SRT and VTT exports.
  Fixtures: a 40-second two-voice clip generated from macOS `say` so no third-party recording is
  committed, a hand-authored WhisperX response for it, and a separate edge-case response.
- **Slice B2, the transcript tab.** One player shared through the video library's own context;
  virtualised paragraph rows; follow, seek, search, low-confidence tooltips; every §5 state rendered
  with its own words. Inline corrections, speaker reassignment, rename with a merge warning, and the
  exports. The Playwright spec first took 3.8 minutes because the failed state waited out the
  production retry ladder; split so the failed state comes from a terminal recording instead, and the
  whole spec now runs in 22 seconds. The spec's hydration watcher then caught, on the production
  image in the gate, a bug that had already shipped in S1: the details tab's Ready timestamp used
  `toLocaleString`, so a server rendering in UTC and a browser in Kolkata produced different text.
  Fixed with a deterministic UTC string on both sides, swapped to local time after mount, tested
  across three time zones.
- **Slice C, the substrate.** A frozen copy of the legacy substrate and scorers at mitosia-legacy
  commit b642b77 under `tools/legacy-reference`, never imported by an app. A dump script renders
  every fixture through it, and a test fails when the committed renderings go stale. The Python port
  covers the cut grid, renderers, paragraphs, lead-in, and cutter helpers, byte for byte against the
  frozen copy. The eval runner is re-hosted with its snapshots and the `temnia-eval` CLI. Four
  fixtures (empty, the legacy snippet converted, speech-40s with measured shots, synthetic edges);
  all four matched the oracle on the first run. The three recorded sources join in slice D once Modal
  exists.

## Went wrong

- **A double-payment bug caught in review, not in production.** Slice A's poll loop only heartbeated
  when a progress note existed, so a slow GPU cold start could run past the five-minute timeout with
  no heartbeat sent, and the retry would then spawn a second GPU job for the same work, the exact
  cost the design exists to prevent. Caught before the gate. Two hardening items went in alongside
  it: failures classified by exception type, and the Modal function refusing the Garage defaults when
  the R2 secret is incomplete.
- **The transcript spec was slow for the wrong reason.** It waited out the real retry ladder to reach
  the failed state instead of asserting against a recording of it. Fixed as noted above.
- **A timezone bug from S1 surfaced under the new hydration watcher.** `toLocaleString` on the Ready
  timestamp rendered differently on the UTC server and a browser set to Kolkata, which only a
  prod-build hydration check would catch. Fixed and tested across three zones.
- **Two PRs open at once.** #19, opened by another session, and #20 from today's work, against the
  one-PR-at-a-time rule. Noted, not resolved.
- **A script name trap for the one-PR rule.** `pnpm pr:verified -- push` maps to the script's `pr`
  mode and would try to open a second PR; pushing to an already-open PR needs
  `node scripts/verified-pr.mjs push` directly. Written down so the next session doesn't rediscover
  it by opening #21.

Day 2 of building Temnia. Sprint two is the transcript: the two-hour episode that came in yesterday gets a word timeline with speakers, the reader that goes with it, and the grid the editing lanes will cut from.

I changed how I work with Claude Code today. Yesterday five smaller agents did the research and the big model wrote the plan from their reports. This morning I asked the big model to redo the same five briefs itself so I could compare. The agents' facts were almost all right. What they missed was in the files they never opened: the legacy's note that our CI fixture has no speech, a duration check that fails a transcript whose words run past the end of the recording, the flag in whisperx that decides whether a word with no diarization overlap gets a speaker. Seven items changed the plan. Ten times fewer tokens, five minutes instead of nine. The rule I'm keeping: wide reading goes to the cheaper agents, and nothing they find becomes a decision until the big model has checked the primary source.

Then the build, orchestrated the same way: one spec per slice, an Opus agent builds, the big model reviews the diff before the gate runs. The review caught the one bug that would have cost real money. The worker polls a GPU job on Modal and heartbeats Temporal only when the job has written a progress note. A slow cold start means no note, no heartbeat, a five-minute timeout, and a retry that spawns a second GPU job. The whole point of the design was never to pay for an encode twice.

The gate caught the other one. Every Playwright run now goes against the production image with a watcher for React hydration errors. It fired on a line that shipped in sprint one: the details tab printed a timestamp with toLocaleString, so the server in UTC and my browser in Kolkata rendered different text. Dev mode never showed it.

The part I'm proudest of is the least visible. The sentence grid and the paragraph rules are ported from the old TypeScript to Python, and the old code sits frozen in the repo as an oracle. A script renders every fixture through the TypeScript; a test fails if the Python output differs by one byte. All four fixtures matched on the first run.

Four slices on one PR in a day. What's left before it runs on staging is on me: the Modal account and two secrets.

### LinkedIn (S2)

Day 2 of building Temnia: the transcript.

Yesterday a two-hour recording could be uploaded and played. Today it can be read. Every word has a time and a speaker, you can click a word to jump the video there, search, fix a misheard word, rename a speaker, and export captions. The transcription itself runs on a rented GPU and costs well under a dollar for a two-hour episode.

Two things I learned about working with AI agents today.

The first is about money. I had the expensive model redo research that cheaper agents had done the night before, to see what the difference was. The cheaper agents got the facts right and missed what was in the files they didn't open. The expensive model, working directly, used a tenth of the tokens and found seven things that changed the plan. So the split now is: cheap agents read widely, the expensive one decides, and nothing becomes a decision without a check against the source.

The second is about review. The expensive model reviewed every piece of code before it was tested, and it caught a bug the tests could not: a case where a slow start on the GPU would have made the system pay for the same job twice. Tests check what you thought to test. A review checks what you forgot.

And one bug from sprint one surfaced today only because the tests now run against the production build, not the developer's. A timestamp rendered in the server's timezone on one side and mine on the other. Small, invisible in development, and exactly the kind of thing a client would have seen first.
